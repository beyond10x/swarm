## Part 1 — what "all found bugs" turned out to be

Sixteen findings were recorded against the 2026-09-12 wave in four `review-result` artifacts. Two
read-only agents re-read every one of them against `main` at `b66ef29` on 2026-09-12. Thirteen are
fixed. Three are open, and one of the three is an accepted, documented bound rather than a defect.

| # | finding | verdict on `main` | where |
|---|---|---|---|
| A1 | the request key is documented as an idempotency key and guards only the append | **open** | `src/runtime/swarm-server/src/http.rs:39` |
| A5 | `Server::open` is a read-then-insert across an await; the second insert replaces a handle that may hold the only copy of an owed delivery | **open** | `src/runtime/swarm-server/src/state.rs:75-85` |
| A6 | `RETRY_DELAY` equals the trigger period, so the retry wait is 30–60s and the upper bound grows with swarm count | **open, accepted** | `swarm.rs:65`, `trigger.rs:66-82` |
| A2, A3, A4, A7, A8, A9, A10 | see `review-result:adversary-unit-a-pass-1` / `-pass-2` | fixed | — |
| B1–B6 | see `review-result:adversary-unit-b-pass-1` / `-pass-2` | fixed | — |
| new | `UiTable` emits `row-click`; the contract table at `index.ts:15-16` does not declare it, so `UiTable` is absent from `uiEmitters` and a table box renders without `:inert` | **open** | `src/web/src/components/ui/index.ts:15` vs `UiTable.vue:15` |

**A6 is not proposed for a fix.** The bound is stated in two places in the code
(`swarm.rs:44-61`, `trigger.rs:66-76`) as a deliberate cost of having one cadence rather than two.
Removing it means a dedicated drain task with its own timer, across `trigger.rs`, `main.rs` and
`swarm.rs`. That is a story somebody decides to write, not a bug fix.

A5 was filed as `story:open-is-a-read-then-insert` by this session, because it had no story. A1 and
the `UiTable` drift already had one.

**A5 remains INFEASIBLE from the shipped surface.** The race is reachable; a *lost delivery* from it
is not, because the only caller of `Server::open` drops its handle without issuing. The fix is one
function.

### What the wave is actually about

Three implementors, working on three unrelated defects in two languages, each wrote a guard, and in
both rounds the adversary broke the guard rather than the fix under it — and broke it the same way
each time:

| round | unit A | unit B | unit C |
|---|---|---|---|
| 1 | a hardcoded list of three documents; a fourth was already wrong | a retry that swallowed the refusal it was written to expose | a parser reading one of three `defineEmits` spellings |
| 2 | matched raw source, so a sentence wrapped across a comment line was invisible — its own file held that case | one lock for all slugs, so an unrelated open waited 253 ms on another slug's replay | matched AST tokens, so three mutants that neuter `inert` while leaving the word in place passed |

Every one is the same error: **the check asserts over the shape of the thing instead of over what
the thing does** — a list instead of a derivation, a token instead of a value, a word instead of an
evaluation. It survived one correction each time by moving one level up the same ladder. The third
version of each guard is the one that stops: unit A normalises the text a reader reads, unit B
serialises per slug on the measurement, unit C evaluates the expressions.

### Two deviations worth the next wave's attention

**An implementor ran `git checkout --` on a file it was editing** (unit A, round 1), to revert a
mutation check, and lost its own uncommitted edits in the same stroke. It redid them and the round
finished green. The brief forbids every git command for exactly this reason, and the rule held no
weight against a convenient way to undo one line. The next brief should say what to use instead —
copy the file into scratch first — rather than only what not to use.

**`npm test` now needs `node_modules`**, because a test imports `@vue/compiler-sfc`. That package
was resolving only because npm hoists it out of `vue`; it is declared now. A fresh worktree's gate
run needs an install first, which the 2026-09-12 wave's record already warned about in general terms.
